# Current-run terminal cleanup drains independently

A failed or quietly cancelled current file command can return its original result while its known-terminal output cleanup continues as observed background work. The cleanup retains exact output ownership, receipt publication and disposal drain until actual settlement. A failed editor handoff with no captured session uses the same boundary; a captured or still-unresolved editor-owned session keeps its existing exact-terminal safeguards.

This is one implementation slice of [#18](https://github.com/rkttu/vscode-csharp-autobuild/issues/18). Full AC6 and [#45](https://github.com/rkttu/vscode-csharp-autobuild/issues/45) remain open. A non-settling filesystem operation can still retain disposal indefinitely. Save, certificate work, editor-owned handoff/session lifetime and other non-cooperative phase policies remain outside this change.
