# File-based app snippet sources

These repository-maintained C# snippets include small adaptations of patterns
from [dotnetdev-kr/dotnet-fba-examples](https://github.com/dotnetdev-kr/dotnet-fba-examples),
reviewed at commit `e75e35665a8d62f9246e51df1e79275c54f010a6`.

- [01-shell-standard.cs](https://github.com/dotnetdev-kr/dotnet-fba-examples/blob/e75e35665a8d62f9246e51df1e79275c54f010a6/01-shell-standard.cs): shebang and source entry-point paths.
- [02-random-webapi.cs](https://github.com/dotnetdev-kr/dotnet-fba-examples/blob/e75e35665a8d62f9246e51df1e79275c54f010a6/02-random-webapi.cs): Web SDK, managed publishing, Minimal API and JSON responses.
- [03-apphost.cs](https://github.com/dotnetdev-kr/dotnet-fba-examples/blob/e75e35665a8d62f9246e51df1e79275c54f010a6/03-apphost.cs): JSON/environment configuration patterns.
- [03-worker.cs](https://github.com/dotnetdev-kr/dotnet-fba-examples/blob/e75e35665a8d62f9246e51df1e79275c54f010a6/03-worker.cs): hosted services and cancellation-aware periodic work.
